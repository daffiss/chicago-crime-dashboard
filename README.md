# Chicago Crime Data Analysis

## About the Project

This project explores crime patterns in Chicago using data from the **City of Chicago Data Portal**. The analysis focuses on the most recent three years of available data to identify trends, patterns, and differences in crime across the city.

Understanding crime data is important for studying urban environments and identifying where and when different types of incidents occur. Data-driven analysis can help reveal patterns that are difficult to see from individual cases and provide a clearer picture of public safety across the city.

## Dataset

The project uses the **Crimes - 2001 to Present** dataset published by the City of Chicago. For this analysis, only the most recent three years of records were used.

The dataset contains information about reported criminal incidents, including:

* crime type and description
* date and time
* location
* geographic information
* arrest status
* domestic-related incidents

## Analysis

The project investigates:

* crime frequency and distribution
* changes in crime over time
* the most common types of crime
* geographic patterns across Chicago
* differences between arrested and non-arrested cases
* patterns by time of day and other available characteristics

## Technologies

* Python
* Pandas
* DuckDB
* Plotly
* Streamlit

## Goal

The main goal is to turn a large and complex public dataset into an interactive and understandable analysis that highlights meaningful crime patterns in Chicago.
